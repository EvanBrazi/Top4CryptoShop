توثيق تسجيل الدخول

  • تسجيل الدخول التقليدي: استخدم اسم المستخدم وكلمة المرور
  • تسجيل الدخول عبر Google: انقر على زر "الدخول عبر Google"
  • تسجيل الدخول عبر Apple: انقر على زر "الدخول عبر Apple"
  • الأمان: جميع كلمات المرور مشفرة باستخدام bcrypt
  • التوكن: يتم إنشاء JWT Token بعد تسجيل الدخول الناجح
